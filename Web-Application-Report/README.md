Web Application Penetration Test Report

This repository contains a professional-style web application penetration testing assessment performed on a password store application.

Scope

Authenticated black-box assessment of a web application and REST APIs.

Key Vulnerabilities Identified

User Enumeration

Missing Rate Limiting

Broken Access Control (IDOR)

Session Mismanagement

Server-Side Request Forgery (SSRF)

Information Disclosure

Attack Chain Demonstrated

Enumeration → Brute Force → Account Access → IDOR → Session Persistence → SSRF

Report

Full professional report available in /report folder.

Evidence

Proof-of-concept screenshots stored in /evidence.
